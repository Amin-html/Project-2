# 🖥️ PCBooking

Сервис бронирования компьютеров — Проект 2 из 10.

## Стек
- Python 3.13 + Django 5.2
- SQLite
- Docker

## Функционал
- 🖥️ Каталог компьютеров с фото и характеристиками
- 🏷️ Фильтр по зонам — Стандартная, Игровая, VIP
- 🔐 Регистрация и вход
- 📅 Бронирование на дату и время
- ⚠️ Проверка что время не занято
- ❌ Отмена бронирования
- 👤 Личный кабинет

## Запуск

```bash
git clone https://github.com/Amin-html/Project-2.git
cd Project-2
docker-compose up --build
```

Открой: `http://127.0.0.1:8000`

## Зоны
| Зона | ПК | Цена/час |
|---|---|---|
| Стандартная | R-1 (i5 + 3060) | 80 сом |
| Игровая | R-2 (i7 + 4070) | 200 сом |
| VIP | R-3 (i9 + 5080) | 600 сом |
